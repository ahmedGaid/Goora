fee rows never say Goora holds the 40, the 4 EGP fee starts at trip 6, the fee balance settles, goes amber when overdue and blocks posting, the bundle counts

## 2. How I walked it (read this before trusting a row)

- **Demo clock.** Settings → Demo only has: ride day 7:15 · before 9 PM · after 9 PM · real time. No "+24 h" or "run N more trips". Every row marked *(clock)* used
  `flutter.debug.demoNow` in `FlutterSharedPreferences.xml` via `adb run-as` (the same trick `goora-status` records). Trips settle per calendar day when the clock
  passes them, so one jump = N days of trips.
- **Marks.** The signed-in user is never a passenger in their own car, so "driver marks me ماستلمتش → I switch back and owe" is not reachable by UI. Rows marked
  *(injected)* used one `wallet.cashMarks` entry for rider `me`, outcomes `didNotPay` / `received`. The driver-side screens (marks, "Marked unpaid" + correction)
  were walked for real on seeded passengers.
- **Seats.** The marketplace seed has no seats on this route in any clock position I tried (Tue 6:30, Thu 14:00, Fri 6:30, Sun 5:30), so **Book on a seat was never reachable**.
  The same gates were walked through **Post your trip**, which the specs also cover.
- **Unverified rider.** A rider can only reach Trust/Wallet after joining, which needs ID, so the "not verified" Trust row (009 US2-3) was walked with
  `trust.riderId = notVerified` injected on a joined account.
- **Language.** Arabic (RTL) first for every flow; English for: driver wallet + marks, rider debt/"I paid", Plan screen, subscribe, wallet top, ID check,
  Today. English match result, pay-method, bundle and settle sheet were **not** re-walked. 1.3× text scale (`settings put system font_scale 1.3`): wallet (fee + overdue
  banners), settle sheet, Fawry settle, ID check, Post form. The 1.3× pay-method screen was seen live but its PNG was overwritten — no file.
- Taps came from `uiautomator dump` bounds, never from a screenshot's pixels (`flutter-lessons` #15). Emulator only; personal phone untouched.
